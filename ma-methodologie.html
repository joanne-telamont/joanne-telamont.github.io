Ma méthodologie

Découvrir → Comprendre → Concevoir → Piloter → Déployer → Mesurer → Améliorer

1. Découvrir — Objectif : comprendre le contexte

Avant toute solution, je cherche à comprendre :

  • les objectifs du projet
  • les attentes du métier
  • les contraintes
  • les utilisateurs
  • les risques

2. Comprendre les utilisateurs

Une fois le contexte compris, il faut comprendre les utilisateurs.

Je cherche à répondre à des questions comme :

  • Qui utilise le service ?
  • Pourquoi ?
  • À quel moment ?
  • Quelles difficultés rencontre-t-il ?

Outils :

  • Personas
  • User Journey
  • Empathy Map
  • Questionnaires
  • Interviews

3. Concevoir

C'est ici que les idées deviennent des solutions.

Je transforme les besoins en fonctionnalités :

  • Animation d’ateliers
  • Co-conception
  • Priorisation
  • Spécifications fonctionnelles
  • Wireframes
  • Maquettes Figma
  • Roadmap

4. Piloter

Une fois la solution validée : on organise le projet.

Cela comprend :

  • planning
  • roadmap
  • coordination
  • priorités
  • reporting
  • gestion des risques
  • communication

5. Déployer

Quand le projet est terminé, il faut accompagner son lancement.

Cela comprend :

  • communication
  • documentation
  • formation
  • accompagnement
  • conduite du changement

6. Mesurer

Un projet ne s'arrête jamais au lancement. Il faut mesurer :

  • la satisfaction
  • les KPI
  • les performances
  • les usages

Outils :

  • Google Analytics
  • Power BI
  • Dashboard
  • Questionnaires

7. Améliorer

La dernière étape consiste à améliorer continuellement le service, grâce :

  • aux retours utilisateurs
  • aux analyses
  • aux benchmarks
  • à la veille
